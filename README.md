# MHS - Melrose High School Fall Varsity Athletic Schedule 2026

A modern, standalone Progressive Web App (PWA) displaying the complete 2026 Fall Varsity Athletic Schedule and Match Matrix for Melrose High School.

## Features

- **Live Standalone Web App**: Add to Home Screen (iOS) or Add to Dock (macOS) with custom native icon and full notch / safe area support.
- **Dynamic OS Theme Support**: Automatically detects and reflects system Light and Dark appearance in real time.
- **Manual Theme Controls**: Quick toggle button (`Auto 💻` / `Dark 🌙` / `Light ☀️`) in the top navigation.
- **Chronological & Sport Views**:
  - Master Date Schedule with quick search filter & Home/Away location pills.
  - Category view broken down by sport: Girls' Volleyball, Boys' Soccer, Girls' Soccer, Football, Field Hockey, Cross Country, and Golf.
- **100% Self-Contained**: Single-file architecture with zero external runtime dependencies.
